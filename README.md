# 🏦 OOP Banking Simulator

A banking app built with Python OOP and Streamlit.

🔗 **Live app:** <paste your streamlit.app link>

## Features
- Create customers and open Current or Savings accounts
- Deposit, withdraw and transfer with validation
- Savings accounts with minimum balance and interest
- Transaction statements

## Concepts used
Encapsulation, Inheritance, Polymorphism, Abstraction, custom exceptions

## Run locally
```bash
pip install -r requirements.txt
streamlit run ooprevision.py
```
